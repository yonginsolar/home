## 🎯 Main Features / 주요 기능

### 1. 단체 조합원 대표자 지정 시스템
**Files:** `vote/candidate_apply.html`, Database schema
**Version:** v1.0.9

단체 조합원이 후보 출마 시 대표자를 지정할 수 있는 기능 추가

#### 기능 상세:
- **조합원 대표자 선택**
  - 조합원 번호로 검색
  - 이름, 생년월일 자동 조회
  
- **비조합원 대표자 등록**
  - 이름, 생년월일, 전화번호 직접 입력
  
- **데이터베이스 스키마**
  - `candidates.representative_type` (TEXT): 'member' 또는 'non-member'
  - `candidates.representative_member_id` (TEXT): 조합원 번호
  - `candidates.representative_name` (TEXT): 대표자 이름
  - `candidates.representative_birth` (TEXT): 생년월일
  - `candidates.representative_phone` (TEXT): 전화번호

#### 검증 로직:
- 단체 조합원은 대표자 정보 필수 입력
- 개인 조합원은 대표자 필드 비표시
- 수정 모드에서 기존 대표자 정보 자동 로드
