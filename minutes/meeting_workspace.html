회의 기본정보

정기총회만 전년도 감사·결산·배당·사업계획 자료를 연결합니다. 임시총회는 등록한 의안만 사용합니다.
같은 해의 기존 이사회·총회를 보고 다음 회차를 제안합니다. 실제 회차와 다르면 바로 수정하세요.
기본값은 총회 개최연도의 전년도입니다. 회계관리에서 다른 연도 보고서를 승인할 때만 바꾸세요.

회의 구성 기준

현재 임원·대의원 명단을 기준으로 자동 채우며 필요하면 회의 당시 수치로 고칠 수 있습니다.

진행 문구와 준비 메모

입력한 내용은 회의 전 문서의 메모·참고사항에 반영됩니다.
보고·의결·논의할 안건을 적으면 회의자료와 진행 시나리오에 반영됩니다.

📚 정기총회 자료집 입력

사업보고·사업계획·예산·차입금 한도를 입력하면 의안과 자료집 본문에 반영합니다. 금액은 쉼표를 자동 표시하고 수입·지출 합계가 다르면 바로 알려드립니다.

자료집에서는 입력한 순서대로 번호 목록으로 표시합니다.

수입 예산

지출 예산

이사회는 기존 회의자료와 시나리오 형식으로 준비합니다. 총회 자료집은 기존 HTML 순서대로 챕터를 골라 한 부분씩 수정할 수 있습니다.

정기총회 연동 자료

문서함·회계·배당·감자·탈퇴 관리에서 정기총회에 필요한 자료를 확인합니다. 없는 조건부 안건은 자료집에서 자동으로 빠집니다.

총회 연동 자료를 확인하는 중입니다.
감사보고서는 결산 완료 자료를 기준으로 만들며, 감사가 직접 수정할 수 있습니다. 한 명이라도 서명하면 본문과 서명 대상은 잠겨 이후 변경할 수 없습니다.
입력 내용 자동 반영
총회 자료집 PDF는 표지 뒤 3쪽과 뒷표지 앞 최소 2쪽을 제본 여백으로 둡니다. 여백에는 번호를 넣지 않고 실제 자료 첫 쪽부터 하단 번호를 연속 표시하며, 전체 물리 쪽수는 짝수가 되도록 자동 보정합니다. 인쇄 창에서 브라우저 머리글·바닥글은 끄고 양면·긴 변 넘김 또는 인쇄소의 책자 설정을 사용하세요.
총회 자료집 순서
정기총회는 조합 업무자료를 연결하고, 임시총회는 등록한 의안만 구성합니다. 챕터를 고쳐 쓰거나 추가·삭제·이동할 수 있습니다.
이 챕터 뒤에 PDF 자료 붙이기자동 연동 자료가 없으면 비워 두거나, 별도로 만든 PDF를 붙일 수 있습니다. 자료집 인쇄 시 PDF의 각 쪽이 이 챕터 바로 뒤에 합쳐집니다.

새 회의 준비

회의 종류를 고르면 기존 회의를 기준으로 다음 회차와 제목을 제안합니다. 제안값은 지금 또는 작업공간에서 언제든 수정할 수 있습니다.
