ERP 처음 쓰기 가이드

오늘 할 일, 업무 찾기, 조합과 권한 확인

목차

  1. 오늘 처리할 일부터 보기
  2. 기능을 찾고 사라진 메뉴 확인하기
  3. 업무 화면을 옮기기 전에 초안 확인

1. 오늘 처리할 일부터 보기

ERP 전체 메뉴 → 내 업무 모아보기

  1. 오늘 할 일에서 지금 처리할 항목을 누릅니다. 해당 문서나 업무가 바로 열립니다.
  2. 방금 처리한 건이 목록에 남아 있다면 목록의 새로고침으로 갱신합니다.

2. 기능을 찾고 사라진 메뉴 확인하기

왼쪽 업무 메뉴 → 검색

  1. 메뉴 이름이나 업무 이름을 검색합니다. 모바일에서는 업무 메뉴를 열거나 검색 버튼을 사용합니다.
  2. 메뉴가 보이지 않을 때는 먼저 지금 열어 둔 조합이 맞는지 확인합니다. 같은 조합에서 필요한 업무만 보이지 않으면 관리자에게 해당 메뉴 권한을 요청합니다.

3. 업무 화면을 옮기기 전에 초안 확인

작성 중인 화면 → 초안 저장 또는 임시저장

  1. 작성 입력과 첨부를 확인하고, 화면에 초안 저장 기능이 있으면 저장 결과를 확인합니다.
  2. 작성 화면을 그대로 두고 안내를 보려면 가이드 문서를 새 탭에서 엽니다.
