근무·휴가·교육 가이드

마이페이지에서 내 근무를, 교육·행사 관리에서 참석을 확인

목차

  1. 내 휴가와 전사 일정 확인
  2. 내 급여·계약·증명서 찾기
  3. 교육 등록부터 참석·피드백까지

1. 내 휴가와 전사 일정 확인

마이페이지 → 근무·휴가 / 전사 일정

  1. 사용 가능 휴가와 휴가 상세를 열어 현재 연차, 사용·조정과 지난 기록을 확인합니다.
  2. 휴가를 신청할 때는 전자결재에서 신청 날짜와 시간을 선택하고 표시된 사용 가능 연차를 확인합니다.

2. 내 급여·계약·증명서 찾기

마이페이지 → 급여 / 증명서·계약

  1. 급여는 확인할 귀속월을 선택합니다. 근로계약은 계약판과 서명 상태를 확인합니다.
  2. 증명서가 필요하면 재직 또는 경력 중 목적에 맞는 서식을 선택하고 저장·출력 전에 미리봅니다.

3. 교육 등록부터 참석·피드백까지

교육·행사 관리 → 교육 등록 → 출석 관리

  1. 교육명과 시간·장소·강사를 입력합니다. 비조합원 신청을 받을 때만 해당 옵션을 켭니다.
  2. 저장 후 사전 신청, 현장 출석, 익명 피드백 QR을 목적에 맞게 사용합니다. 교육 시작 뒤 사전 신청은 마감되고 명단은 출석 관리에서 볼 수 있습니다.
  3. 교육이 끝나면 출석 관리에서 누락된 참석을 수기로 추가하고 받은 피드백을 확인합니다.
