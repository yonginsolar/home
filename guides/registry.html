1. 어떤 변경인지 먼저 구분

ERP 이용 가이드 → 등기·변경신고 업무 → 변경 업무 진행관리

  1. 바뀐 항목과 효력일, 근거가 되는 총회·이사회 의사록을 확인합니다.
  2. 관할 기관 변경신고, 법원 변경등기, 등기 후 정정은 각각 다른 업무입니다. 해당하지 않는 단계는 진행관리에서 건너뜁니다.
  3. 정관을 바꾼 경우 신고 또는 인가 절차와 별도로, 등기부에 적힌 항목도 바뀌는지 확인합니다.
등기 진행관리 업무 (로그인)

2. 시청 변경신고 서류 준비

ERP 이용 가이드 → 등기·변경신고 업무 → 시청 변경신고

  1. 신고 유형을 선택하고 현행 양식의 변경 전·후 칸에 들어갈 항목을 확인합니다.
  2. 변경 이유와 날짜를 근거 문서에서 확인합니다. 출자 관련 변경이면 직전 신고에서 확인된 값과 이번 신고 기준의 값을 각각 대조합니다.
  3. 준비서류 체크리스트에서 해당 유형의 의사록·신구대조 자료·명부 등을 확인합니다. 조합원 명부(별지 제6호)는 해당하는 경우에만 챙깁니다.
  4. 주사무소 이전은 관할과 주소를 증명할 첨부를 확인하고, 접수 뒤 신고확인증을 보관합니다.
등기 진행관리 업무 (로그인)

3. 변경등기 진행 순서

ERP 이용 가이드 → 등기·변경신고 업무 → 변경등기 가이드

  1. 변경 유형을 고르고 준비서류부터 확인합니다. 여러 항목이 함께 바뀌면 일괄 변경, 주사무소 이전은 별도의 이전 경로를 확인합니다.
  2. 인터넷등기소에서 대상 법인 → 등기사유 → 신청권한 → 등기할 사항 순서로 작성합니다. 직접 제출과 대리 제출에 필요한 서류를 구분합니다.
  3. 납부 영수증·첨부서류를 대조한 다음 신청서 출력과 서명·날인을 확인하고, 관할 등기소의 제출 방식에 맞춰 접수합니다.
등기 진행관리 업무 (로그인)

4. 변경 유형별로 확인할 자료

변경등기 가이드 → 변경 유형

  1. 출자금·출자좌수: 출자금 및 출자좌수 변동내역 확인서, 직전 등기액, 이번 기준일의 납입총액과 좌수를 대조합니다.
  2. 임원: 취임·중임·퇴임·사임을 구분해 의사록·승낙서·사임서 등 해당 사유의 증빙을 확인합니다.
  3. 이사장: 선임 근거와 대표자 변경, 인감 관련 서류와 신고확인증을 확인합니다.
  4. 명칭·사업 목적: 바뀐 정관, 변경 의결을 담은 의사록과 신고·인가 자료를 확인합니다.
  5. 주사무소 이전: 의사록과 주소 증빙을 확인하고 이전 전·후 관할, 정관 변경 여부에 따라 필요한 자료를 확인합니다.
등기 진행관리 업무 (로그인)

5. 후속 정정과 경영공시

ERP 이용 가이드 → 등기·변경신고 업무 → 변경 업무 진행관리 / 경영공시

  1. 공증·변경신고·등기 접수일과 근거 의사록을 각각 기록해 다음 할 일을 남깁니다.
  2. 대표자·주소가 바뀌면 은행·사업자등록과 해당 발전소의 발전사업허가·전력계약·REC 정보 중 바꿀 것만 확인합니다.
  3. 경영공시는 조합 유형과 기준연도를 확인한 뒤 조직·조합원·총회·결산 자료를 대조하고 기존 공식 포털로 이어갑니다.
등기 진행관리 업무 (로그인)
