회의·의사록 가이드

총회와 이사회 준비, 감사 제출, 의사록 마감

목차

  1. 총회 기본정보 저장
  2. 안건 고르고 순서 맞추기
  3. 감사 제출 마감 확인
  4. 결산보고서를 전달하고 날짜 남기기
  5. 자료집 확인하고 회의자료 완성
  6. 의사록에서 준비한 총회 불러오기
  7. 참석을 체크하고 안건 결과 기록
  8. 전자서명을 받고 의사록 마감
  9. 가결된 안건만 후속 업무로 연결
  10. 신고·등기와 발전소 정정 확인
  11. 이사회 준비
  12. 결재·게시
  13. 의사록·서명

정기 대의원총회는 아래 10단계를 따라가세요. 이사회와 소집 공문, 의사록·서명은 목차에서 바로 열 수 있습니다.

1. 총회 기본정보 저장

회의·문서·서명 → 회의 꾸러미 → 새 회의 준비 → 기본정보

  1. 새 회의 준비에서 총회(대의원총회)와 정기총회를 선택합니다. 이미 만든 총회는 왼쪽 목록에서 엽니다.
  2. 회계연도, 공고일, 회의일, 시작·종료 시각과 장소를 확인합니다.
  3. 기본정보 저장을 누릅니다. 총회일을 바꾸면 감사 제출 마감도 함께 바뀝니다.
회의 꾸러미 업무 (로그인)
예시 화면 보기 · 회의 준비

2. 안건 고르고 순서 맞추기

회의 꾸러미 → 해당 정기총회 → 안건

  1. 기본 안건 불러오기에서 필요한 안건을 고릅니다. 목록의 위로·아래로·빼기로 순서를 정리합니다.
  2. 지난 총회에서 가져올 때는 필요한 안건의 틀만 선택합니다. 지난 총액·결과·첨부는 따라오지 않습니다.
  3. 기타는 안건 추가로 직접 넣습니다. 의결 안건은 정관 변경·임원 변경처럼 종류를 골라 저장합니다.

탈퇴 조합원 출자금 환급은 이번 총회에서 의결할 대상이 있을 때만 기본 안건에 나타납니다.

회의 꾸러미 업무 (로그인)
예시 화면 보기 · 회의 준비

3. 감사 제출 마감 확인

ERP 메인 → 내 업무 모아보기 → 오늘 할 일

  1. 감사에게 결산보고서 제출을 누르면 해당 총회를 바로 엽니다.
  2. 총회 14일 전부터 제출 안내가 한 건 나타납니다. 총회가 3월 28일이면 3월 14일부터 보이고, 마감은 3월 21일입니다.

총회를 7일 전에 등록했다면 그날부터 마감 안내를 확인할 수 있습니다.

내 업무 모아보기 (로그인)회의 꾸러미 업무 (로그인)
예시 화면 보기 · 내 업무 모아보기

4. 결산보고서를 전달하고 날짜 남기기

회의 꾸러미 → 총회 기본정보 → 총회 전 점검

  1. 연결 자료 보기에서 해당 회계연도의 확정 결산보고서를 확인합니다. 보고서는 감사에게 따로 전달합니다.
  2. 실제 제출일에 감사에게 보낸 날짜를 넣습니다.
  3. 제출 기록을 누르면 해당 판본의 알림이 내려갑니다. 저장 버튼이 보고서를 보내지는 않습니다.

결산보고서를 수정해 다시 확정하면 새 판본의 제출 여부를 확인합니다.

회의 꾸러미 업무 (로그인)
예시 화면 보기 · 총회 전 점검

5. 자료집 확인하고 회의자료 완성

회의 꾸러미 → 해당 총회 → 회의 전 문서

  1. 안건이나 순서가 달라졌다면 입력 내용으로 준비문서 다시 만들기를 누릅니다.
  2. 자료집의 총회 순서·의안과 진행 시나리오를 대조한 뒤 회의 전 자료 전체 저장으로 남깁니다.
  3. 회의자료 완성을 누릅니다. 의사록은 완성된 자료집의 안건 순서를 가져옵니다.

총회 소집 공문에는 저장한 총회 자료집을 기존 공문 불러오기 흐름에서 연결합니다.

회의 꾸러미 업무 (로그인)
예시 화면 보기 · 회의 전 문서

6. 의사록에서 준비한 총회 불러오기

의사록 → 작성 → 대의원총회 의사록

  1. 문서유형에서 대의원총회 의사록을 고르고 준비한 총회 불러오기를 누릅니다.
  2. 날짜와 제목이 같은 총회를 선택합니다.
  3. 선택한 총회 불러오기를 누르면 일시·장소·안건이 채워집니다. 기존 참석 체크·본문·첨부는 바뀌지 않습니다.

목록에 없으면 회의자료 완성 여부를 확인하세요. 이미 의사록에 연결한 총회는 새 작성 목록에 다시 나오지 않습니다.

7. 참석을 체크하고 안건 결과 기록

대의원총회 의사록 작성 → 참석 대의원 → 안건별 결과

  1. 실제로 참석한 대의원을 체크합니다. 단체 대의원은 실제 참석자 이름도 입력합니다.
  2. 안건 옆의 필요한 찬성 수를 확인합니다. 찬성 인원 표시만으로 결과가 가결되지는 않습니다.
  3. 결과에서 가결·부결·보류를 고르고, 보고 안건은 확인 또는 보류를 기록합니다. 기명날인인은 기존 방식대로 정합니다.

재적 과반이 참석하기 전에는 필요한 찬성 수가 표시되지 않습니다. 합병·분할·해산은 대의원총회에서 가결로 기록하지 않습니다.

8. 전자서명을 받고 의사록 마감

의사록 → 목록·관리 → 서명 개시 → 마감하기

  1. 본문과 안건 결과를 미리보기로 대조한 뒤 저장합니다. 저장 직후 ‘열람 중’이면 서명이 끝난 상태가 아닙니다.
  2. 서명 개시를 누른 뒤 기존 서명 현황에서 필요한 사람의 서명이 모두 들어왔는지 확인합니다.
  3. 마감하기를 누릅니다. 서명 진행 중에는 후속 업무가 열리지 않습니다.

공개하기는 마감과 별도입니다.

9. 가결된 안건만 후속 업무로 연결

마감한 의사록 → 미리보기 → 후속 업무 확인

  1. 마감한 의사록의 미리보기에서 후속 업무 확인을 누릅니다.
  2. 가결된 안건 중 변경신고·등기 또는 환급이 필요한 것만 나옵니다. 할 일 만들기를 눌러 의사록이 연결된 진행관리 초안을 만듭니다.
  3. 환급은 출자금 환급 관리 열기로 가서 대상자별로 처리합니다. 같은 안건을 다시 눌러도 진행관리 건이 중복되지 않습니다.

할 일을 만들어도 신고·등기나 출자금 지급이 실행되지는 않습니다.

10. 신고·등기와 발전소 정정 확인

ERP 이용 가이드 → 등기·변경신고 업무 → 변경 업무 진행관리 → 연결된 변경 건

  1. 근거 회의록이 맞는지 확인하고 공증·변경신고·등기 상태를 각각 기록합니다. 신고만 하는 안건에는 등기를 건너뜁니다.
  2. 발전소 후속 정정에는 실제 영향받는 발전소만 추가합니다. 발전사업허가·전력계약·REC 중 해당하는 것을 확인합니다.
  3. 업무를 마친 뒤 진행상태 저장을 누릅니다. 은행·세무서 정정이 필요한 경우 같은 변경 건에서 이어서 확인합니다.

이사회 준비

새 회의 꾸러미 만들기

회의·문서·서명 → 회의 꾸러미 만들기 → 새 회의 준비

  1. 회의 종류를 ‘이사회’로 고릅니다.
  2. 회차와 제목을 적고 ‘만들기’를 누릅니다. 왼쪽 목록에 새 회의가 생기고 기본정보가 열립니다.
회의 꾸러미 업무 (로그인)

날짜와 장소 저장하기

기본정보 → 기본정보 저장

  1. 공고일·회의일·시작과 종료 시각·장소를 적습니다. 진행 담당·의장·재적 이사 수를 확인합니다.
  2. 배포 자료에 넣을 말은 ‘회의자료에 넣을 메모’, 내부 준비에만 쓸 말은 ‘비공개 준비 메모’에 적습니다.
  3. ‘기본정보 저장’을 누르고 저장 안내를 확인합니다.
회의 꾸러미 업무 (로그인)

안건 저장하기

안건 → 안건 추가 → 안건·자료집 입력 저장

  1. ‘안건 추가’를 누르고 보고·의결·토의·기타 중 하나를 고릅니다. 제목과 설명을 적습니다.
  2. 위·아래 화살표로 순서를 맞추고 ‘안건·자료집 입력 저장’을 누릅니다. 이사회는 여기까지 하면 소집 공문에 안건을 가져올 수 있습니다.
회의 꾸러미 업무 (로그인)

배포자료와 진행 대사 확인하기

회의 전 문서 → 이사회 회의자료 / 의장용 / 실무자용

  1. 고칠 문서에서 ‘편집’을 누릅니다. 글이나 PDF 별첨은 연결할 안건을 골라 넣습니다.
  2. ‘이 문서 저장’은 현재 문서만, ‘회의 전 자료 전체 저장’은 준비 문서를 함께 저장합니다.
  3. ‘인쇄·PDF 저장’에서 배포할 자료를 확인하고, 준비를 끝냈으면 ‘회의자료 완성’을 누릅니다.

결재·게시

소집 공문에 회의 내용 넣기

전자결재 → 결재 올리기 → 공문 → 공문 종류

  1. ‘이사회 소집’ 또는 ‘총회 소집’을 고르고 회의꾸러미를 선택합니다. ‘회의 내용 불러오기’를 누릅니다.
  2. 제목·수신·일시·장소·안건을 읽어 봅니다. 이미 적은 내용이 있으면 교체 여부를 확인합니다. 총회 수신 문구가 대의원인지 조합원인지 확인합니다.
전자결재 업무 (로그인)

소집 공문 상신하고 결재 완료 확인하기

공문 용도·결재선 확인 → 상신 미리보기 → 상신하기

  1. 용도·첨부·결재선을 확인합니다. ‘상신 미리보기’에서 보낸 사람과 내용을 확인하고 ‘상신하기’를 누릅니다.
  2. 결재자는 ‘전자결재 → 결재할 문서’에서 소집 공문 제목을 누릅니다. 본문·결재선·첨부를 확인하고 ‘승인’을 누른 뒤 확인창에서 ‘승인 완료’를 누릅니다.
  3. 기안자는 마지막 결재 뒤 ‘결재 이력’에서 완료 표시를 확인합니다.
  4. 이사회 소집 공문이 결재되면 안건의 제목·목록과 발행된 공문이 확정됩니다. 기본정보와 안건의 설명·분류·순서, 회의자료는 계속 편집할 수 있지만 발행본에는 반영되지 않습니다. 제목·목록은 변경 소집 공문으로 바꿉니다.
  5. 총회 소집 결재 후에는 기본정보와 안건 제목·구성도 잠깁니다.
전자결재 업무 (로그인)

결재된 소집 공문 열기

회의·문서·서명 → 회의·문서 관리 → 공문 → 내부용

  1. 결재 완료 공문에서 ‘내용 보기’를 눌러 최종 내용을 확인합니다. 닫으면 같은 공문의 게시 설정으로 돌아옵니다.
전자결재 업무 (로그인)

소집 공지를 게시하기

공문 목록 → 홈페이지 공지 / 문서함 → 게시 설정 적용

  1. 게시할 곳을 고릅니다. 필요한 경우 ‘첨부 포함’을 체크하고 ‘게시 설정 적용’을 누릅니다. 같은 카드의 ‘홈페이지 공개’·‘문서함 게시’ 표시를 확인합니다.
  2. 외부용 공문은 ‘출력·PDF 저장’이나 ‘첨부 다운로드’를 사용합니다. 공지 게시와 참석자 개별 발송은 별개입니다.
전자결재 업무 (로그인)
의사록·서명

실제 회의 정보로 새 의사록 열기

회의·문서 관리 → 의사록 → 새 문서 작성·업로드

  1. 문서 유형을 고르고 제목과 실제 회의 일시·장소를 입력합니다. 배석자가 있으면 적습니다.
  2. 이사회는 실제 참석 이사를 체크합니다. 총회는 참석 대의원과 기명날인인을 확인합니다. 현재 총회 화면의 참석자 목록은 전체 조합원 명부가 아니라 대의원 명단입니다.
의사록 업무 (로그인)

회의 결과 확인하고 의사록 저장하기

회의 내용 → 저장 전 미리보기 → 저장하기

  1. 논의·의결 결과를 적고 폐회 선언으로 끝냅니다. 회의 준비 문서는 실제 의사록을 대신하지 않습니다.
  2. ‘저장 전 미리보기’로 본문·날짜·조합명·서명란을 읽어 봅니다. 닫고 ‘저장하기’를 누른 뒤 ‘문서 조회’에서 방금 저장한 의사록을 찾습니다.
