1. 원천세 신고

회계 관리 → 신고·결산 매뉴얼 → 원천세 정기신고

  1. 정기신고에서 사업자 정보와 지급연월을 먼저 맞춥니다. 귀속연월은 승인 급여대장, 지급연월은 실제 지급 전표에서 확인합니다.
  2. 급여의 간이세액(A01)은 해당 대상과 인원·총지급금액·세액을 급여대장과 대조합니다. A99 총합계는 자동 집계이므로 확인만 합니다.
  3. 지급이 확인된 강사비 등은 근로소득과 섞지 않고 해당 소득 구분으로 확인합니다. 부표가 필요한 경우 기존 자료를 확인하고 작성합니다.
  4. 신고서의 최종 합계와 접수증을 확인하고, 지방소득세는 같은 귀속·지급 기간과 관할을 위택스에서 대조합니다.
  5. 신고서와 실제 납부 증빙을 보관합니다. ERP의 결재·회계에는 국세·지방세와 실제 납부일을 구분해 기록합니다.

작성완료, 신고서 제출, 세금 납부는 각각 다른 단계입니다.

2. 부가가치세 신고와 카드 공제

회계 관리 → 신고·결산 매뉴얼 → 부가가치세

  1. 홈택스에서 예정고지·예정신고 여부와 실제 신고 기간을 먼저 확인합니다. 이미 반영한 예정분을 중복 입력하지 않습니다.
  2. 매출은 세금계산서·카드·현금영수증·기타 증빙을 대조합니다. 취소와 증빙이 겹치는 건을 먼저 정리합니다.
  3. 매입은 일반매입과 고정자산매입, 불공제를 구분합니다. 법인카드는 사업용신용카드의 매입세액 공제 확인·변경 화면에서 해당 내역을 검토합니다.
  4. 최종 신고서에서 납부·환급액을 확인하고 접수증과 증빙을 남깁니다. 실제 통장 출금과 납부 내역을 대조해 전표를 정리합니다.

공급가액과 세액을 나눠 확인하고, 카드 사용액을 공제액으로 그대로 옮기지 않습니다.

3. 연말결산

회계 관리 → 연말결산

  1. 조합과 회계연도를 확인하고 통장 잔액, 장부, 전표 누락·중복, 결산 조정이 필요한 계정부터 대조합니다.
  2. 결산 미리보기의 계정별 숫자와 원장을 확인합니다. 확인 후 원장이 바뀌어 경고가 나오면 새 미리보기부터 다시 확인합니다.
  3. 결산 자료와 보고서를 보관하고, 총회에 올릴 보고서와 감사에게 전달할 판본이 같은지 확인합니다.

4. 법인세 · Smart A

회계 관리 → 신고·결산 매뉴얼 → 법인세

  1. 확정 결산보고서와 재무제표를 준비한 뒤 Smart A에서 사업자 정보와 해당 사업연도를 확인합니다.
  2. ERP 확정 값과 Smart A의 표준재무제표를 대조합니다. 세무조정·소득 구분을 확인한 뒤 해당 서식의 확인된 칸에 입력합니다.
  3. 전자신고 파일을 만들고 변환 결과와 신고서를 확인합니다. 접수증과 실제 납부 내역은 각각 보관합니다.

실시간 장부 합계가 확정된 신고 세액을 대신하지 않습니다.
