연합회 시범 현황판

조합의 현황은 한눈에, 회비와 공동사업은 한곳에서.

ERP 전체 메뉴
관리자 열람 초안 연결 조합의 실제 집계를 조회합니다. 회비 계산은 연습용이며 청구·납부·알림은 실행하지 않습니다.

로그인과 연합회 열람 권한을 확인합니다.

연결 조합 현황

정조합원·출자 잔액·발전소는 현재 등록 기준입니다.

조합원 수는 조합별 합계로, 여러 조합에 가입한 동일인을 중복 제거한 시민 수가 아닙니다.

수집된 발전량

미수집을 0으로 계산하지 않습니다. 회비 확정에는 산정 기간과 수집 범위 확인이 필요합니다.

발전소와 참여 사업

집계 기준 보기

연결된 발전소·모니터는 하나로 묶습니다. 조합 참여 용량은 발전소 전체 용량과 구분합니다. 같은 발전소·같은 달은 직접 입력값, 모니터 월간값, 모니터 일간 합계 순으로 한 자료만 사용합니다.

참여 사업의 발전량은 기존에 등록한 직접 입력·지분율·참여용량 기준을 유지합니다. 직접 입력 기준에 모니터 전체 발전량을 임의로 대입하지 않습니다. 수집분은 연간 확정 발전량이 아닙니다.

회비 산정·납부

실제 회비 규칙과 납부자료는 아직 연결하지 않았습니다.

계산 연습

저장되지 않음

전년도 기준·최소회비 100,000원을 초깃값에 반영했습니다. kW(설비용량)·kWh(발전량) 중 실제 산정 단위와 단가는 확인 중입니다. 아래는 발전량(kWh) 방식의 시험 계산입니다.

기본회비 + 선택 연도 수집 발전량 × 단가로 계산합니다. 실제 규정이 구간제라면 규칙 확인 후 별도로 연결합니다.

정식 회비 운영 흐름
  1. 산정 규칙과 기준 발전량을 확인합니다.
  2. 회비를 확정해 조합별 납부할 일로 표시합니다.
  3. 납부기한과 입금 내역을 대조합니다.
  4. 미납·일부 납부·납부 완료·면제를 구분하고 변경 이력을 남깁니다.

예상액 계산만으로 납부할 일이나 미납 상태를 만들지 않습니다. 추후 실제 청구와 납부 확인은 각각 별도 권한으로 관리합니다.

공동사업·지원

기획 초안

아래는 화면 구성 제안입니다. 실제 모집·신청·지원 기록은 만들지 않았습니다.

함께 추진하기

공동사업

공동구매·보험·교육 사업별로 안내, 참여 조합, 신청기한, 조합별 담당자와 진행 상태를 묶습니다.

연합회 공고 → 조합 참여 신청 → 확인·진행 → 결과 공유

필요한 곳을 연결하기

지원 요청

회계·조합원 관리·발전소 운영 등 조합의 요청을 접수하고 담당자, 답변, 처리 상태를 확인합니다.

접수 → 담당 배정 → 확인 중 → 해결·종료

다시 제출하지 않도록

연간 보고

확정 기준일의 회원·출자 통계와 연간 발전량을 보고용으로 묶고, 자료가 없는 항목은 확인 대상으로 남깁니다.

현황 자동 집계 → 누락 확인 → 보고용 확정본

연합회 시범 열람 권한은 각 조합의 업무 권한과 분리됩니다. 개인별 회원정보·계좌·결재문서는 조회하지 않습니다.
