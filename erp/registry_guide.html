등기유형에서 출자/자산사항의 변경을 선택합니다.

실제 주사무소 이전은 별도의 관할내·관할외 주사무소이전 유형에서 시작합니다. 이전 절차는 추가 확인 후 안내합니다.

대상법인 선택·등기의 사유 입력
  1. 대상법인 조회 → 상호검색을 누릅니다.
  2. 현재 등기된 조합명으로 검색합니다.
  3. 검색 결과에서 법인등록번호와 조합명을 확인해 해당 조합을 선택합니다.
  4. 진행을 누릅니다.
  5. 등기의 사유에 이번 변경 사항과 근거 날짜를 입력합니다.
  6. 저장 후 다음을 누릅니다.

등기의 목적은 특수법인 변경등기로, 제출등기소는 조회한 법인 기준으로 자동 표시됩니다. 표시된 등기소를 확인하고 필수 항목인 등기의 사유를 작성하세요.

신청권한 확인이 나타나면 인증정보는 직접 입력합니다. 명칭을 변경하는 경우에는 등기부의 변경 전 명칭으로 검색하세요.

등기할사항 입력

일괄 변경 유형 선택

종전·새 주소의 관할을 확인하고 인터넷등기소에서 주사무소 이전의 관할 내·외 유형을 고르세요.

주사무소 이전은 21일 이내에 종전 소재지 또는 새 소재지에서 등기합니다. 이후 화면과 납부·첨부 요건은 해당 이전 유형에서 확인하세요.
